# Discover Madang — Tourism Website Starter

A multi-page HTML/CSS/JS prototype based on the Madang tourism architecture developed in the project.

## Open locally
Open `index.html` in a browser. For best results, serve the folder with a local server (for example VS Code Live Server).

## Main pages
- index.html — cinematic homepage
- destinations.html — destination explorer
- destination.html — reusable destination detail page
- experiences.html — experience hub
- experiences/*.html — Adventure, Ocean, Culture, Wildlife, Culinary
- stories.html — editorial archive
- stories/story.html — story template
- plan.html — trip planning
- journey-builder.html — interactive itinerary builder
- contact.html — contact placeholder

## Important
The visual imagery currently uses remote Unsplash demo images. Replace these with properly licensed Madang/PNG photography and video before publishing. Practical travel facts, operators, accommodation, dates, prices, safety information and historical claims should be verified against authoritative/current sources before the site is used publicly.
